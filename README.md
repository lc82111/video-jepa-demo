# Improving World-Model with Residual Latent Transitions, Action-Discriminative Representations, and Horizon-Adaptive Planning

Static GitHub Pages companion for the Push-T study of Residual Latent Transitions (RLT), Action-Discriminative Representations (ADR), and Horizon-Adaptive Planning (HAP).

The page runs entirely in the browser. The interactive traces are lightweight representative browser-rendered cases; the quantitative cards and downloadable exports use the figure-checked values from the research workspace. Available MP4s are labeled as recorded reference clips because this workspace does not contain a paired Native CEM/HAP video set.

Open `index.html` locally or serve this directory with any static web server. No package install or GPU is required.
