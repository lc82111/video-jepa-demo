# Learning Better Latent Dynamics, Planning Better Paths

Static GitHub Pages companion for the Push-T residual-dynamics and HADP study.

The page runs entirely in the browser. The interactive traces are lightweight representative browser-rendered cases; the quantitative cards and downloadable exports use the figure-checked values from the research workspace. Available MP4s are labeled as recorded A5 reference clips because this workspace does not contain a paired Native CEM/HADP video set.

Open `index.html` locally or serve this directory with any static web server. No package install or GPU is required.
